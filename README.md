# 📋 Task Management System

A production-ready full-stack Task Management application built for an internship assignment. It features a responsive UI, robust REST API, search, filter, sort, and pagination capabilities.

## 🔗 Live Links
- **Live Frontend (Vercel)**: [https://task-management-system-30it1v77z.vercel.app/](https://task-management-system-30it1v77z.vercel.app/)
- **GitHub Repository**: [https://github.com/hariom-p1306/task-management-system](https://github.com/hariom-p1306/task-management-system)

## 🚀 Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Deployment**: Vercel (Frontend Static Site), Render (Backend Web Service)

## ✨ Features
- **Task CRUD Operations**: Seamlessly create, read, update, and delete tasks.
- **Search, Filter & Sort**: Filter tasks by status and priority, search by title or description, and sort by creation date.
- **Pagination**: Smooth handling of large lists with clean pagination controls.
- **Centralized Error Handling**: Robust error responses on both backend and frontend layers.
- **Responsive UI**: Modern user interface styled with Tailwind CSS, optimized for all screen sizes.
